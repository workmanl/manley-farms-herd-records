Offline field guide

Open Herd Records

Prepare before leaving signal

Open the app online and wait for Ready offline. On iPhone or iPad Safari, open Share and choose Add to Home Screen. On Android Chrome, use Install app or Add to Home screen in the menu. On desktop Chrome or Edge, use the address-bar install control. On Mac Safari use Add to Dock where available. Firefox can use the app in an ordinary tab; install support varies.

Installation is optional. Browser and installed contexts may have separate records. Verify your herd and a saved backup in each context.

In the field

Open Animals, choose the dam and Add calf. Confirm the birth date and identity before saving. For treatment, enter the actual administration and supplied meat and milk instructions. Unknown stays Needs review. Wait for Saved on this device before leaving a form.

Keep and restore records

In Backup & Settings download JSON, save outside the browser, then select the file to verify it. Confirm saved only after saving the file. Restore starts with a preview; replacement also requires a saved, verified copy of the current records. Keep copies in two places. Airplane mode does not prevent local exports, restore or report preparation.

Updates and drafts

Updates download only while connected. Update when ready waits until every Herd Records tab is free of unsaved changes and calf drafts. Save or explicitly discard drafts, and close older tabs that cannot coordinate. A schema change requires a freshly saved and verified backup. An interrupted download keeps the old shell. Recovery retains records if migration fails.

Storage and recovery

No cloud copy or automatic sync exists. Clearing site data, private browsing, eviction or losing a device can remove records. Request persistent storage and keep external backups. If recovery appears, export the existing records and pre-migration snapshot; use a compatible release. Never clear storage to fix an update.
